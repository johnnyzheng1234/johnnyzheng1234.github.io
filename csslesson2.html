What is a div element

The div tag is a block-level element used to group HTML elements or for scripting purposes

What is one way you can identify or "target" a div element?

to assign it a unique ID attribute

Why would you use a div element

The div element is used as a generic, non-semantic container to group other HTML elements.

What is a border property?

A CSS border property is a shorthand property that sets the style, width, and colour of an element's border in a single declaration.

What are some of the different border properties?

The main properties include setting the width, style, and colour, along with more advanced properties for rounding corners or using an image.

What is the difference between margins and padding?

Padding adds space inside an element, while margin adds space outside an element.
